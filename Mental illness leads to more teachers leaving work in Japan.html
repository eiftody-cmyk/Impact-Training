精神的な負担で退職する教員が過去最多に

💡 使い方 (How to use): 単語をクリックすると、下のボックスに「読み方（かな）」と「意味（英語）」が表示されます。

日本 の 文部科学省 の 調査 によると、2024 年度 に 心 の 不調 を 理由 に 退職 した 公立 学校 の 教員 は 1,319 人 で、 過去最多 に なりました。 この 数 は、 前回 の 調査 と 比べて 約39 ％ 増えています。 教員 の 精神的 な 負担 が 大きく なっている こと が、 改めて 明らかに なりました。

このような 増加 の 背景 には、 特別 な 支援 が 必要 な 学生 が 増えている こと や、 慢性的な 教員不足 が あります。 学校現場 では、 一人 の 教員 が 担当する 業務 が 増え、 長時間労働 や ストレス が 大きな 問題 に なっています。

文部科学省 は、 教員 が 深刻 な 状態 に なる 前 に 発見 できる よう、 ストレスチェック を 行ったり、 相談 できる 場所 を 増やしたり して、 働きやすい 環境づくり を 進める 方針 です。
