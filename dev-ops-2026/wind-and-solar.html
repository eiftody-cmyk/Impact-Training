風力と太陽光が初めてガスを上回る

💡 使い方 (How to use): 単語をクリックすると、下のボックスに「読み方（かな）」と「意味（英語）」が表示されます。

世界 で 初めて、 4月 に 風力 と 太陽光 で 作られた 電力 が、 ガス を 上回りました。 研究所 「Ember」 の 調査 によると、 風力 と 太陽光 は 世界 の 電力 の 22パーセント を 占めました。 一方、 ガス は 20パーセント でした。

この 結果 は、 中東 の 紛争 による エネルギー 危機 の 反応 ではなく、 より 広い トレンド の 一部 です。 世界中 の 国 が、 安くて 国内 で 生産 でき、 安全 な 電力 として、 風力 や 太陽光 を 選んでいます。

現在 の エネルギー 危機 は、 再生可能 エネルギー を 使う 経済的 な 理由 を さらに 強く しています。
